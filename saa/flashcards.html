플래시카드

SAA-C03에는 판단으로 풀 수 없고 알고 있어야만 풀리는 항목이 있습니다. 서비스와 용도의 대응, 확인된 한도값, 열거 목록이 그렇습니다. 이 페이지는 그 항목들을 간격 반복(spaced repetition)으로 익히는 도구입니다. 읽는 것이 아니라 떠올리는 것이 목적입니다.

진도는 브라우저에 저장되므로 여러 번에 나누어 돌려도 이어집니다. 도메인 지식은 도메인 페이지 네 개가, 쌍 단위 구분은 함정 사전이 담당합니다.

학습 목표

  • 암기가 필요한 항목과 판단으로 푸는 항목을 구분해 학습 시간을 배분할 수 있습니다.
  • 간격 반복의 졸업 규칙에 맞춰 자기 진도를 관리할 수 있습니다.
  • 카드를 키보드만으로 넘기며 인출 연습을 할 수 있습니다.
  • 졸업하지 못한 카드를 근거로 다시 볼 챕터를 고를 수 있습니다.

카드 돌리기

앞면을 보고 답을 먼저 소리 내어 말하거나 떠올린 뒤 뒤집으십시오. 보고 나서 "아, 맞아"라고 느끼는 것은 학습이 아닙니다. 떠올리지 못한 카드는 주저 없이 몰랐음으로 기록해야 간격 반복이 제 역할을 합니다.

덱 데이터가 아직 준비되지 않았으면 위 자리에 안내 메시지가 표시됩니다. 정상 동작입니다.

또한 이 페이지를 file://로 직접 열면 브라우저가 JSON 로드를 차단합니다. 로컬에서 확인할 때는 정적 서버로 열어야 카드가 표시됩니다.

간격 반복 규칙

규칙은 하나뿐입니다. 알았음을 3회 연속으로 고르면 그 카드는 졸업하고 기본 출제 대상에서 빠집니다. 중간에 한 번이라도 몰랐음을 고르면 연속 기록과 졸업이 모두 초기화되어 처음부터 세 번을 다시 맞혀야 합니다.

카드 상태와 다음 동작
상태 의미 다음에 할 일
연속 0회 아직 맞힌 적이 없거나, 직전에 몰랐음을 골랐습니다 답을 확인한 뒤 관련 챕터를 짧게 다시 봅니다
연속 1~2회 기억이 붙는 중입니다. 아직 안정적이지 않습니다 같은 세션에서 몰아 맞히기보다 날짜를 나누어 다시 돌립니다
졸업 (연속 3회) 기본 출제 대상에서 빠집니다 시험 직전에 졸업 카드 제외를 끄고 한 번 훑어 확인합니다

연속 3회를 한 자리에서 채우면 효과가 거의 없습니다. 방금 본 답을 다시 맞히는 것은 인출이 아니라 단기 기억 확인이기 때문입니다. 하루에 한 번씩 사흘에 걸쳐 졸업시키는 편이 같은 횟수로 훨씬 오래 갑니다.

진도는 이 브라우저에만 저장됩니다. 시크릿 창을 쓰거나 브라우저 저장 데이터를 지우면 연속 기록과 졸업 상태가 사라집니다. 다른 기기로 옮겨 가지도 않습니다.

카드는 마우스 없이 전부 조작할 수 있습니다. 한 손을 키보드에 두고 돌리는 편이 속도가 훨씬 빠릅니다.

무엇을 외우고 무엇을 외우지 않는가

플래시카드를 잘못 쓰는 가장 흔한 방식은 판단으로 푸는 것까지 외우려는 것입니다. 시나리오 문항은 암기로 풀리지 않습니다. 아래 기준으로 나누십시오.

암기 대상과 판단 대상의 구분
구분 예 학습 도구
외워야 하는 것 확인된 한도값, 열거 목록(Route 53 라우팅 정책 8종 등), 서비스와 한 줄 용도의 대응 이 페이지의 플래시카드
구분할 수 있어야 하는 것 혼동되는 개념 쌍의 결정적 차이 함정 사전
해석할 수 있어야 하는 것 한정어가 가리키는 선택지와 배제하는 선택지 한정어 키워드 사전
판단할 수 있어야 하는 것 요구사항에서 아키텍처를 고르는 일 문제 풀이와 도메인 페이지

암기가 실제로 점수로 이어지는 대표 항목은 수치가 판단을 가르는 경우입니다. S3 Standard-IA와 One Zone-IA의 최소 저장 기간 30일, Glacier 계열의 90일과 180일, 그리고 gp3의 현행 상한이 그렇습니다. 이 값을 모르면 "더 저렴한 클래스로 옮긴다"가 왜 손해인지 판단할 수 없습니다.

권장 사용 방식

학습 단계별 플래시카드 사용법
시기 사용 방식
챕터를 막 읽은 직후 그 챕터에 해당하는 카드만 돌립니다. 개념이 아직 붙어 있을 때가 인출 효과가 가장 큽니다
학습 기간 중 하루에 짧게 여러 번. 한 번에 오래 돌리는 것보다 날짜를 나누는 것이 중요합니다
모의고사 직후 틀린 문항과 관련된 카드를 우선 돌립니다. 오답 노트와 함께 씁니다
시험 전날 졸업 카드 제외를 끄고 전체를 한 번 훑습니다. 새 카드를 추가로 파지 않습니다
시험 직전 카드 대신 벼락치기 요약을 봅니다. 이 시점에는 통독이 더 효율적입니다

한 세션의 목표를 "덱 전체 완주"가 아니라 "몰랐음 카드 찾기"로 잡으십시오. 모르는 카드를 찾아내는 것이 이 도구의 목적이고, 찾아낸 뒤에 담당 챕터로 돌아가는 것이 실제 학습입니다.

이어서 볼 곳

  • 벼락치기 요약 확인된 한도값과 열거 목록을 표로 모았습니다. 카드로 외운 것을 한 번에 대조할 때 씁니다. 시험 대비
  • 함정 사전 암기가 아니라 구분이 필요한 항목입니다. 쌍마다 결정적 차이를 한 문장으로 정리했습니다. 시험 대비
  • 오답 노트 같은 간격 반복 규칙이 문항에도 적용됩니다. 3회 연속 정답이면 졸업합니다. 문제 풀이
  • 문제 풀이 허브 암기로 풀리지 않는 시나리오 판단은 문항으로 훈련합니다. 도메인 연습과 모의고사가 있습니다. 문제 풀이
  • 시험 개요와 8주 플랜 플래시카드를 학습 일정의 어디에 넣을지 정할 때 봅니다. 시험 대비
  • 한도·기본값 빠른참조 카드로 외우는 수치의 원본 목록입니다. 확인된 값만 담겨 있습니다. 빠른참조

공식 문서 출처

  • SAA-C03 시험 가이드 — 카드가 다루는 범위의 기준이 되는 도메인과 과제 진술
  • AWS Lambda 개발자 안내서 — 할당량 — 한도값 카드의 근거
  • Amazon SQS API 레퍼런스 — CreateQueue — 큐 속성 기본값과 범위 카드의 근거
  • Amazon S3 사용 설명서 — 스토리지 클래스 사용 — 최소 저장 기간과 최소 청구 크기 카드의 근거
  • Amazon EC2 API 레퍼런스 — CreateVolume — EBS 볼륨 타입 카드의 근거
  • Amazon Route 53 API 레퍼런스 — ResourceRecordSet — 라우팅 정책 여덟 가지 카드의 근거
